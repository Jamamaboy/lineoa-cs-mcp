ตัวที่ควรอ่านก่อน

  1. omnichat-bridge ใกล้โจทย์ที่สุด อ่าน ส่ง และส่งไฟล์ผ่าน endpoint ภายในของ chat.line.biz ได้ครบ มี test 995 ข้อ เป็นของบริษัทไทย
  2. LINELib ครบที่สุดในฝั่ง LINE ทั้ง login, ส่ง, อัปโหลด 2 ขั้น และ SSE เป็นแหล่งอ้างอิงเรื่อง endpoint
  3. telegram-mcp ต้นแบบเรื่อง auth และไฟล์แนบ: guard ว่าเป็นบัญชีที่ตั้งไว้, จำกัดโฟลเดอร์ไฟล์ (allowed roots), ดาวน์โหลดแบบ atomic, จำกัดขนาดหลายชั้น
  4. slack-mcp-server ต้นแบบเรื่องเปิดการส่งแบบ opt-in + allowlist และการคืนไฟล์แนบเป็น MCP image content (จำกัด 5 MB)
  5. Chatwoot ต้นแบบ domain model ได้แก่ Conversation, Message, Attachment (file_type: image/audio/video/file/location/fallback) และ ContactInbox

สิ่งที่จะเพิ่มหรือเปลี่ยนในแผน (จากงานวิจัยรอบนี้)

รอบ 4: เพิ่มอีก 6 ตัว (Intercom MCP, Zendesk, Freshchat, Trengo, ChatCone, OHO Chat)

ทั้งหมดเป็น SaaS ปิด ไม่มีบัญชีทดลอง จึงอ่านจากเอกสารสาธารณะเป็นหลัก ตัวที่ได้รันจริงมีตัวเดียวคือ zendesk-mcp-server ของชุมชน (pytest)

เรื่องสิ่งที่ได้ได้มาจาก
ยืนยันแนวทางinbox ที่รองรับ LINE (Zendesk, Freshchat) ต่อผ่าน Messaging API webhook ทั้งหมด Zendesk ต้องตั้ง Response mode เป็น Bot ด้วย จึงอ่านประวัติเก่าที่ CS เห็นในหน้าเว็บไม่ได้ เหตุผลที่เราใช้ session ของหน้าเว็บจึงยังหนักแน่นZendesk, Freshchat
ขอบเขต toolMCP ทางการของ Intercom เน้นอ่าน มี tool เขียนตัวเดียวคือ internal note ไม่ส่งหาลูกค้า สอดคล้องกับแนวทางของเราที่ปิดการส่งเป็นค่าเริ่มต้น (LINEOA_ALLOW_SEND)Intercom MCP
ไฟล์แนบtool รูปของ zendesk-mcp-server ใช้ allowlist MIME, ตรวจ magic bytes, จำกัดขนาดระหว่าง stream (10 MB) และไม่ส่ง Authorization ต่อไปยัง CDN ภายนอก ตรงกับ PLAN §7 ส่วน Freshchat มีสถานะสแกนไวรัส (file_security_status) ไว้ใช้เป็นไอเดียZendesk, Freshchat
ข้อจำกัดของ LINEFreshchat ส่งรูปและวิดีโอได้สองทาง แต่ไฟล์รับได้อย่างเดียว ต้องยืนยันใน HAR ว่าหน้าเว็บ chat.line.biz ส่งไฟล์ (PDF) ได้จริงผ่าน bulkSendFilesFreshchat

สิ่งที่ยังไม่มีใครทำ (จุดที่งานของเราจะต่างออกไป)

  • ไม่มีโปรเจกต์ไหนเป็น MCP server สำหรับ LINE OA ในนามพนักงาน CS ที่เจอใกล้ที่สุดคือ extension (omnichat-bridge) กับ library (LINELib)
  • ไม่มีใครทำ mock backend + contract test ที่ทำให้ test ได้โดยไม่ต้องมีบัญชีจริง
  • ไม่มีใครทำ search ภาษาไทยเลย ของเราใช้ FTS5 trigram และจำกัดโฟลเดอร์ outbox ตอนส่งไฟล์ให้ลูกค้า
