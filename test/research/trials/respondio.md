# respondio (SaaS, no account, not-run)
WebFetch https://respond.io/help/line/line-overview (updated 05 Sep 2026):
- Image up to 1 MB sent with preview; 1-10 MB converted into link. Audio 200 MB, Video 200 MB.
- Sticker receive yes, send no. Contact cards and Flex messages unsupported -> fallback "Unsupported Message"/"Custom Payload" (expandable JSON). Unsupported/oversize files -> URL link.
- No LINE messaging window while in contact list; contacts must message first; no history import mentioned. Webhook setup not covered in this article.
