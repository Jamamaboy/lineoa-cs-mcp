1. สรุปสั้นที่สุด

  • สร้างอะไร: MCP server ที่ให้ AI (เช่น Claude) ทำงานในหน้าแชท LINE OA Manager (chat.line.biz) แทนพนักงาน CS ได้ คือดูรายการแชท อ่านแชท ค้นข้อความ ตอบลูกค้า และดูโปรไฟล์
  • ให้ใคร: ทีม CS ของ OA Acme Support ซึ่งเป็นที่ลูกค้าแจ้งปัญหา (ส่วน OA หลักของ Acme คือตัวแอปที่ลูกค้าใช้บันทึกรายรับรายจ่าย)
  • เข้าบัญชียังไง: CS login เองใน browser จริงครั้งเดียวต่อกะ server เก็บแค่ session cookie แล้วเรียก API ภายในของหน้าเว็บ ไม่เคยเห็นรหัสผ่าน และไม่ใช้ Messaging API เพราะอ่านแชทเก่าและค้นหาไม่ได้
  • ไฟล์แนบ: ในแชทส่งแค่ข้อมูลไฟล์ จะโหลดไฟล์จริงก็ต่อเมื่อ AI ขอ รูปจะถูกย่อแล้วส่งให้ AI เห็น ไฟล์อื่นบันทึกลงเครื่องแล้วคืน path · ส่งไฟล์ได้เฉพาะจากโฟลเดอร์ outbox
  • ของแถมที่ทำให้ต่าง: ชั้นเคส (1 แชทมีหลายเคส แท็ก สถานะ สถิติ) และ webUrl ลิงก์ให้ CS กดไปคุยเองในหน้าเว็บ
  • ความปลอดภัย: ปิดการส่งไว้เป็นค่าเริ่มต้น · แอป AI ถามอนุญาตก่อนส่งทุกครั้ง · ปิดบังอีเมลและเบอร์โทร · บันทึก log ทุกการส่ง

2. ผลสุดท้ายหน้าตาเป็นยังไง (มี 3 จอ)

4. Tool 13 ตัว

ต้องมี

9. สิ่งที่ยังไม่รู้

  • endpoint ของ chat.line.biz มาจากการอ่านโค้ดของคนอื่น ยังไม่ได้ยืนยันกับของจริง รอไฟล์ HAR จาก OA จริง (อ่านอย่างเดียว) และ OA ทดสอบ
  • ยังไม่รู้ว่าหน้าเว็บส่ง PDF ได้ไหม และมี API ค้นข้อความหรือเปล่า (ถ้าไม่มี เราค้นจาก index ในเครื่อง)
  • ข้อความ "ชำระค่าบริการ ฿X,XXX" ทุกวันใน OA หลัก เป็นการเตือนหรือตัดเงินซ้ำ ต้องถาม Acme
  • รอตัดสินใจ: ข้อเสนอ 5 ข้อจากรีเซิร์จรอบ 5 (จำกัดการส่งต่อวัน, ENDPOINT_CHANGED, redirect = หมดอายุ, กรองสติกเกอร์, บอกชัดว่าอ่านไม่ mark read)
