CS เปิดใช้งานยังไง และเทคนิคในตารางอยู่ตรงไหนของระบบ

อ้างอิง docs/PLAN.md §1, §6, §7 · ตัวอย่างหน้าจอเป็นภาพจำลอง

สรุปสั้น: ตารางเทคนิคที่แปะมาคือเบื้องหลังที่ทำงานอยู่ข้างใน server ซึ่ง CS ไม่เห็นเลย ส่วนสิ่งที่ CS เห็นมีแค่ แอป Claude (หรือ AI client ตัวอื่น) ที่มี "ปลั๊กอิน LINE OA" เพิ่มเข้ามา ใช่ เราเสนอได้เลยว่า "เราสร้าง tool ชุดหนึ่ง (MCP server) แล้วโชว์ว่า AI ใช้มันดูแลแชทได้จริง" เพราะนั่นคือสิ่งที่โจทย์ขอพอดี

1. ภาพรวม: CS เห็นอะไร และเทคนิคอยู่ตรงไหน

2. ตารางเทคนิค: ใช้ทำอะไรในระบบของเรา

เทคนิคในงานของเราใช้ตรงไหนเป็นทางหลักไหมCS เห็นไหม
Playwrightเปิด browser จริงให้ CS login เอง (รวม 2FA / captcha) แล้วเก็บ cookie · ถ้า endpoint ไหนเรียกตรงไม่ได้ ค่อยใช้คลิกหน้าเว็บแทนเป็นทางสำรองใช้ตอน loginเห็นแค่ browser เด้งขึ้นมาตอน login
Browser Sessionใช้ cookie ของ CS ที่ login ไว้ เก็บใน session.json สิทธิ์ 600 · ไม่เก็บรหัสผ่าน · ตรวจว่าเป็นบัญชีที่ตั้งไว้ · หมดอายุแล้วบอก AUTH_EXPIREDหลักไม่เห็น
Network Inspectionศึกษาว่าหน้าเว็บเรียก API อะไร (HAR + repo ที่รีเซิร์จ) แล้ว server เรียก API เดียวกันตรง ๆ เร็วกว่าและพังยากกว่าการคลิกหน้าเว็บหลักไม่เห็น
DOM Inspectionอ่านข้อมูลจากหน้าเว็บ ใช้เป็นทางสำรองเท่านั้น เพราะถ้าหน้าเว็บเปลี่ยน class / layout ก็พังทันทีสำรองไม่เห็น
File Handlingget_attachment: รูปย่อแล้วส่งให้ AI เห็น ไฟล์ใหญ่บันทึกลงเครื่องแล้วคืน path · ส่งไฟล์ได้เฉพาะจากโฟลเดอร์ outbox · ตรวจชนิดและขนาดไฟล์หลักเห็นรูปในแชทกับ AI
เราเลือก "login ด้วย browser + เรียก API ตรง" แทน "ให้ Playwright คลิกหน้าเว็บทุกครั้ง" เหตุผลนี้เขียนไว้ใน PLAN §6 แล้ว และจะใส่ใน README เป็น trade-off ซึ่งเป็นคำถามที่ grader น่าจะถาม

3. CS เปิดใช้ยังไง: ติดตั้งครั้งเดียว 3 ขั้น

1

ติดตั้ง server (IT หรือ CS ทำครั้งเดียว)

$ git clone …/lineoa-cs-mcp && cd lineoa-cs-mcp $ npm install && npm run build
2

Login LINE (ทำต้นกะ ถ้า session หมดอายุ)

$ npm run login Opening browser… sign in to LINE Business ID ✓ Logged in as มิ้นท์ · OA: Support ✓ Session saved (chmod 600)

browser จริงเด้งขึ้นมา CS กรอกเองทุกอย่าง server ไม่เคยเห็นรหัสผ่าน

3

บอกแอป Claude ว่ามี server นี้ (ครั้งเดียว)

Claude Desktop: Settings → Developer → Edit Config แล้ววาง

{ "mcpServers": { "lineoa-cs": { "command": "node", "args": ["…/dist/server.js"], "env": { "LINEOA_ALLOW_SEND": "true" } } } }

Claude Code (สำหรับ grader / dev) คำสั่งเดียว

$ claude mcp add lineoa-cs -- node dist/server.js

ถ้ามีเวลา: แพ็กเป็น Desktop Extension ให้ CS ดับเบิลคลิกติดตั้งได้เลย ไม่ต้องแก้ JSON

5. ใช้ได้ 2 แบบ ด้วย server ตัวเดียวกัน

แบบ A CS คุยกับ AI เอง

  • เปิด Claude Desktop แบบในข้อ 4
  • AI ช่วยสรุป ค้นหา ร่างคำตอบ CS เป็นคนกดส่ง
  • เหมาะกับตอนเดโมให้ grader ดู

แบบ B agent อัตโนมัติของธุรกิจเอง

  • โจทย์พูดถึง "our automation agent" คือโปรแกรมที่รันเองตามรอบ เช่นทุก 15 นาที
  • ใช้ tool ชุดเดียวกัน เช่น ดึงแชทใหม่ แท็กเคส สรุปลงโน้ต
  • ค่าเริ่มต้นปิดการส่ง (LINEOA_ALLOW_SEND=false) ให้คนตรวจก่อน
