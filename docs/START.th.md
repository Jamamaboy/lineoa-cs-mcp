# เริ่มใช้งาน lineoa-cs (สำหรับทีม CS บน Mac)

หน้านี้พาคุณตั้งแต่เครื่องที่ยังไม่มีอะไรเลย ไปจนถึงถาม AI ว่า "มีแชทไหนรอตอบบ้าง" ใช้เวลาประมาณ 10 นาที
ค่าเริ่มต้นเป็น **อ่านอย่างเดียว** AI จะไม่ส่งข้อความหาลูกค้าจนกว่าคุณจะเปิดเอง

คู่มือการใช้ต่อจากนี้อยู่ที่ [USAGE.th.md](USAGE.th.md)

## 0. เปิด Terminal

กด `Cmd + Space` พิมพ์ `Terminal` แล้วกด Enter จะได้หน้าต่างสำหรับพิมพ์คำสั่ง

## 1. ติดตั้ง Node

1. เข้า https://nodejs.org แล้วดาวน์โหลดรุ่น **LTS**
2. เปิดไฟล์ที่ได้ แล้วกดถัดไปจนติดตั้งเสร็จ
3. เปิด Terminal ใหม่ แล้วพิมพ์

```bash
node -v
```

ควรเห็น: `v22.13.0` หรือเลขที่สูงกว่า (เช่น `v22.20.1` หรือ `v24.0.0`)

ถ้าเห็นเลขต่ำกว่า 22.13 หรือขึ้นว่า `command not found` ให้ติดตั้ง Node ใหม่อีกครั้ง

## 2. เอาโปรเจกต์มาไว้ในเครื่อง

วิธีที่ 1: ใช้คำสั่ง (ถ้ามี git)

```bash
git clone https://github.com/Jamamaboy/lineoa-cs-mcp.git
cd lineoa-cs-mcp
```

วิธีที่ 2: ไม่ใช้ git เข้า GitHub กดปุ่ม **Code → Download ZIP** แล้วดับเบิลคลิกไฟล์ ZIP เพื่อแตกไฟล์
จะได้โฟลเดอร์ `lineoa-cs-mcp-…`

## 3. ติดตั้งและตั้งค่า

### วิธีที่ง่ายที่สุด: ดับเบิลคลิก

ในโฟลเดอร์โปรเจกต์ ดับเบิลคลิกไฟล์ **`start-mac.command`** มันจะตรวจ Node, ติดตั้ง, เพิ่มเข้า Claude
(อ่านอย่างเดียว) และถามว่าจะ login LINE เลยไหม

ถ้าดาวน์โหลดเป็น ZIP แล้วดับเบิลคลิกไม่ทำงาน (เปิดเป็นข้อความแทน) ให้ใช้วิธี "พิมพ์ทีละคำสั่ง" ด้านล่างแทน หรือพิมพ์ `bash start-mac.command` ใน Terminal ที่โฟลเดอร์นี้

ครั้งแรก macOS อาจไม่ยอมเปิดไฟล์ที่โหลดมาจากอินเทอร์เน็ต ให้คลิกขวาที่ไฟล์ → **Open** → กด **Open** อีกครั้ง

### หรือพิมพ์ทีละคำสั่ง

ในโฟลเดอร์โปรเจกต์ (ใน Terminal พิมพ์ `cd ` แล้วลากโฟลเดอร์มาวาง กด Enter)

```bash
npm ci --ignore-scripts      # เหมือน npm install แต่ใช้เวอร์ชันที่ล็อกไว้ และไม่รันสคริปต์ของแพ็กเกจ
```

ควรเห็น: ข้อความประมาณ `added … packages` แล้วกลับมาที่หน้าพิมพ์คำสั่ง ไม่มีบรรทัดสีแดง

```bash
npm run setup
```

ควรเห็น: รายการที่เพิ่มเข้า Claude Desktop และ Claude Code พร้อมบอกว่าเป็นโหมดอ่านอย่างเดียว
(อยากดูก่อนว่าจะเปลี่ยนอะไร ใช้ `npm run setup -- --dry-run`)

ถ้ายังไม่มี Claude Desktop โปรแกรมจะบอกให้ติดตั้งจาก https://claude.ai/download แล้วรัน setup อีกครั้ง
(ข้ามได้ถ้าใช้ Claude Code)

```bash
npm run login
```

ควรเห็น: หน้าต่าง Chrome หรือ Edge เด้งขึ้นมา ให้ login LINE ด้วยตัวเอง พอสำเร็จหน้าต่างจะปิดเอง และใน
Terminal ขึ้น `✓ Logged in as …` พร้อมรายชื่อ OA ที่เข้าได้

สุดท้าย **ปิด Claude Desktop ให้สนิทแล้วเปิดใหม่**

## 4. เลือกแอป AI: Claude Desktop หรือ Claude Code

| | Claude Desktop (แนะนำสำหรับ CS) | Claude Code |
|---|---|---|
| คืออะไร | แอปแชทที่มีหน้าต่างให้พิมพ์ถามได้เลย | โปรแกรมใน Terminal |
| ใช้ยังไง | เปิดแอป พิมพ์ถามเป็นภาษาคน | พิมพ์ `claude` ในโฟลเดอร์โปรเจกต์ |
| คำสั่งที่ต้องรัน | `npm run setup` แล้วเปิดแอปใหม่ | `npm run setup` หรือใช้ `.mcp.json` ในโฟลเดอร์นี้ (มันเสนอ `lineoa-cs` และ `lineoa-cs-mock`) |

ใน Claude Code ที่โฟลเดอร์นี้ จะมีข้อความต้อนรับบอกขั้นต่อไปและตัวอย่างคำถาม

## 5. ลองแบบปลอดภัยด้วยข้อมูลตัวอย่าง

ยังไม่อยาก login หรือยังไม่มีบัญชี LINE? ลองกับข้อมูลปลอมก่อน ข้อมูลนี้ไม่ไปถึง LINE จริง

```bash
npm run setup -- --mock
```

โหมดนี้ลงทะเบียนเฉพาะ `lineoa-cs-mock` (ข้อมูลตัวอย่าง เปิดการส่งข้อความได้เพราะไม่ถึง LINE จริง)
จากนั้นเปิด Claude Desktop ใหม่ แล้วถามว่า

> มีแชทไหนรอตอบบ้าง

อยากดูแบบไม่ต้องมี AI: `npm run try` เป็นทัวร์ 10 วินาทีใน Terminal

## 6. ข้อมูลไปไหน / ปลอดภัยไหม

- **ข้อความแชท ชื่อลูกค้า และรูปที่ AI อ่าน จะถูกส่งไปยังผู้ให้บริการของแอป AI** (เช่น Anthropic สำหรับ Claude)
  ตรวจนโยบายบริษัทเรื่องข้อมูลลูกค้าก่อนใช้กับ OA จริง
- **โปรแกรมไม่เห็นรหัสผ่านของคุณ** คุณ login เองในหน้าต่าง browser โปรแกรมเก็บแค่ session ไว้ที่
  `~/.config/lineoa-mcp/session.json` (เปิดได้แค่คุณ)
- **ต้อง login ใหม่ประมาณวันละครั้ง** เพราะ session ของ LINE หมดอายุ (ทุกวันหรือทุกกะ) รัน `npm run login`
- **อย่ากด "Always allow" ให้ `send_message`** ในแอป AI ถ้ากดแล้ว AI จะส่งโดยไม่ถามคุณอีก
  (การส่งปิดอยู่แล้วตามค่าเริ่มต้น แต่ถ้าคุณเปิดเองด้วย `--allow-send` ให้ปล่อยให้มันถามทุกครั้ง)
- **เรื่องข้อกำหนดของ LINE เป็นพื้นที่สีเทา** การใช้ session ของพนักงานให้โปรแกรมทำงานแทน ควรใช้ที่นั่งของตัวเอง
  ใช้ในปริมาณน้อย และถ้าจะใช้จริงจังในบริษัท ให้ตรวจกับ LINE หรือฝ่ายกฎหมายก่อน
- **การอ่านไม่ทำให้แชทกลายเป็น "อ่านแล้ว"** ลูกค้าจะไม่เห็นว่าอ่านแล้วทั้งที่ยังไม่มีใครตอบ

## 7. เจอปัญหา

| เห็นข้อความนี้ | ทำยังไง |
|---|---|
| `AUTH_EXPIRED` หรือ "Not logged in" | session หมดอายุ รัน `npm run login` |
| `CHOOSE_OA` | บัญชีเข้าได้หลาย OA ให้ตอบชื่อ OA ที่ต้องการ เช่น "ใน OA Demo Shop" |
| `node: command not found` หรือ Node ต่ำกว่า 22.13 | กลับไปข้อ 1 |
| macOS ไม่ยอมเปิด `start-mac.command` | คลิกขวา → Open → Open |
