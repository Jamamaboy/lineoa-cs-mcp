Goal

สิ่งที่ได้เมื่องานนี้ขึ้น

1. คนตรวจเปิด repo แล้วไม่เจอร่องรอยงานค้างหรือโน้ตภายใน มี LICENSE และ npm run check สะอาด ไม่มี warning

2. คน CS ที่ไม่ใช่สายเทคเริ่มใช้เองได้จากหน้าภาษาไทยหน้าเดียว (หรือดับเบิลคลิกไฟล์เดียวบน Mac) รู้ว่าข้อมูลไปไหน และลองกับข้อมูลจำลองใน Claude Desktop ได้

Edge cases

เคสตัดสินใจ
network error ระหว่าง POST ส่งข้อความห้ามห่อ postJson — sendText อาศัยการ throw ที่ไม่ใช่ LineOAError เพื่อรายงาน SEND_UNCERTAIN (line-client.ts:213-217) ห่อแค่ getJson/getBytes
network error ระหว่าง getJson ใน findSent / ดึง CSRF tokenfindSent มี .catch(() => undefined) อยู่แล้ว (line-client.ts:202) · token ดึงก่อน POST → UPSTREAM_ERROR ถูกบันทึกเป็น failed ไม่ใช่ uncertain (ถูกต้อง ยังไม่ได้ส่ง) · wrapper ต้องคง redirect:"manual" และ getBytes ต้องคำนวณ own/cookie ก่อนเรียก wrapper เหมือนเดิม · ข้อความ error ของ host ภายนอกมีแค่ชื่อ host ไม่มี URL/query
send text มีแต่ช่องว่างปฏิเสธที่ zod ก่อนเข้า handler จึงไม่ถูกบันทึกใน audit (ยอมรับได้: ยังไม่มีการพยายามส่ง)
วันที่ 2028-02-29 / 2026-02-29ตรวจด้วยการสร้าง Date แล้วเทียบ y/m/d กลับ: 2028 ผ่าน, 2026 ไม่ผ่าน
